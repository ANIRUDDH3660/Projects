# 🤖 Chatbot Project

A dynamic and interactive chatbot application designed to engage users with intelligent conversation capabilities.

## 📋 Project Overview

- **Backend**: Built with Spring Boot; handles API calls and logic.
- **Frontend**: Developed in React.js; provides a user-friendly interface.
- **Technologies Used**: Spring Boot, Maven, React.js, Vite, Bootstrap, Axios
- **API Integration**: Utilizes Gemini API for natural language processing.

## 🚀 Getting Started

### Prerequisites

- **Java 21**
- **Node.js**
- **Maven**

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ANIRUDDH3660/Projects.git
   cd Projects/Chatbot
   ```

2. **Backend Setup**
   - Navigate to the `Backend` directory
   - Update `application.properties` with valid Gemini API credentials
   - Run `mvn spring-boot:run`

3. **Frontend Setup**
   - Navigate to the `frontend` directory
   - Install dependencies with `npm install`
   - Start the development server with `npm run dev`

### Running the Application

- **Backend** available at: `http://localhost:8080`
- **Frontend** available at: `http://localhost:3000`

## 📖 Usage

- Open the frontend in your browser
- Enter a question in the input field
- Submit to receive intelligent responses generated by the Gemini API
